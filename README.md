#Campus Life – Vie étudiante à YouCode

Site vitrine statique et responsive qui permet aux futurs et nouveaux apprenants de découvrir l'univers de YouCode. Projet réalisé à partir d'une maquette Figma, en HTML et CSS uniquement.

#Pages

• Accueil (accueil.html) : présentation de l'univers Campus Life.
• Inscription (inscription.html) : formulaire permettant de manifester son intérêt pour YouCode.

#Technologies utilisées

• HTML5 
• CSS3
• Figma (maquette de référence)
• Git & GitHub
